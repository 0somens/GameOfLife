## Visión general creada por IA
A tensor is a fundamental data structure in machine learning, representing a multi-dimensional array of numerical data. It is a generalization of concepts like scalars (single numbers), vectors (1D arrays), and matrices (2D arrays) to higher dimensions. In TensorFlow, all data is represented as tensors.
Key properties of a tensor include:
Rank (or dimensions): The number of axes or dimensions a tensor has. A scalar has rank 0, a vector has rank 1, a matrix has rank 2, and so on.
Shape: The size of each dimension of the tensor. For example, a matrix of shape (2, 3) has 2 rows and 3 columns.
Data type (dtype): The type of data stored in the tensor, such as float32, int32, or string.

**TensorFlow** is an open-source platform developed by Google for machine learning and deep learning. It provides a comprehensive ecosystem of tools, libraries, and resources for building, training, and deploying machine learning models.
At its core, TensorFlow operates by defining and executing computations as data flow graphs. In this graph:
Nodes: represent mathematical operations.
Edges: represent the tensors (multi-dimensional arrays) that flow between these operations.
This architecture allows for efficient computation, especially on specialized hardware like GPUs and TPUs, and facilitates the creation of complex machine learning models. TensorFlow supports various programming languages, including Python, and offers APIs for both low-level numerical computation and high-level model building.
